Cove Watchdog - Azure Function App settings
===========================================

Adds every setting the watchdog reads to the Function App, so they are all
visible and adjustable in the Azure portal.

HOW TO USE
  1. Azure portal > your Function App > Settings > Environment variables
  2. Click "Advanced edit".
  3. Put the cursor just before the final ] at the very end of the text.
  4. Paste everything below the COPY BELOW THIS LINE marker.
  5. Click OK, then Apply.
  6. Fill in the REQUIRED values listed below, then Apply again.

DO NOT DELETE the three settings already there. Advanced edit replaces
everything, and the app breaks without them:
  AzureWebJobsStorage
  APPLICATIONINSIGHTS_CONNECTION_STRING
  DEPLOYMENT_STORAGE_CONNECTION_STRING

REQUIRED - the watchdog will not run until these have values:
  COVE_PARTNER    Customer name exactly as the Cove console shows it, INCLUDING
                  the parenthesised email:  Acme Ltd (admin@acme.com)
  COVE_USERNAME   The API user's login name
  COVE_PASSWORD   The API user's token (secret)
  SMTP_HOST       Mail host only, no https:// and no port:  mail.smtp2go.com
  ALERT_FROM      Sender address your mail provider allows
  ALERT_TO        Recipient address(es), comma-separated

USUALLY REQUIRED - most hosted mail providers need a login:
  SMTP_USERNAME
  SMTP_PASSWORD   (secret)

Everything else already has a working default.

Timezone: use a city name such as America/New_York. Never EST - it is
accepted, but ignores daylight saving, so mail arrives an hour late all summer.

Every setting and its accepted format: README.md, "Configuration".
